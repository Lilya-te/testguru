# TEST GURU

## Список сущностей (объектов реального мира) для проекта TestGuru

* Тесты - class Test
* Вопросы тестов - class Question
* Варианты ответов на вопросы тестов - class Answer
* Группы тестов или теги тестов (психология, английский, грамматика русского языка и т.д.) - class Category
* Пользователи - class User
* Прогресс пользователей (начатые тесты, пройденные тесты, статистика) - class UserTest
